## Module 01 — Quotes and Estimates (8 Lessons)
*Turn a walkthrough into a quote before you drive off.*

### Lesson 1: Basic Quote Generator
```
I just walked through a home and here are the details:
- Size: [sq ft / number of rooms and bathrooms]
- Condition: [light / moderate / heavy dirt]
- Special areas: [kitchen grease, pet hair, mold in bathroom, etc.]
- Service type: [standard clean / deep clean / move-in/out]

Generate a professional quote with a price range, what's included, and what's excluded.
```

### Lesson 2: On-Site Walkthrough Notes → Quote
```
Convert these rough walkthrough notes into a professional quote:
[paste your messy notes here]

Format it as: job summary, scope of work, estimated time, price, and payment terms.
```

### Lesson 3: Tiered Pricing Options
```
Client: [name], Property: [address/type]
Walkthrough findings: [what you saw]

Create three quote options:
- Basic (essentials only)
- Standard (most popular)
- Premium (white-glove)

Include what's different in each tier and the price for each.
```

### Lesson 4: Add-On Upsell Script
```
I just gave a client a quote for a standard clean at $[price].
Suggest 3–5 add-on services I could offer (e.g., inside oven, windows, fridge),
with a short one-sentence benefit for each and a suggested price.
```

### Lesson 5: Quote Follow-Up Email
```
I gave [client name] a quote of $[amount] on [date] for [service].
They haven't responded. Write a short, friendly follow-up email
that re-confirms the value and creates soft urgency without being pushy.
```

### Lesson 6: Recurring Service Quote
```
Client wants recurring cleaning for a [size] home, [frequency: weekly/biweekly/monthly].
One-time rate would be $[price].
Build a recurring pricing structure with a discount, and explain the value of locking in.
```

### Lesson 7: Commercial Property Quote
```
Property type: [office / warehouse / retail / restaurant]
Square footage: [sq ft]
Frequency: [daily / weekly / custom]
Special requirements: [floors, restrooms, break rooms, etc.]

Write a professional commercial cleaning proposal with scope, schedule, and pricing.
```

### Lesson 8: Quote Objection Handler
```
Client said: "[their exact objection — e.g., 'your price is too high' or 'I'll think about it']"
My quote was: $[amount] for [service]

Write a confident, non-pushy response that addresses their concern
and keeps the conversation open without immediately dropping my price.
```

## Module 02 — Client Messages (6 Lessons)
*Answer bookings and changes without retyping.*

### Lesson 1: New Booking Confirmation
```
Client: [name]
Service booked: [type of clean]
Date/time: [date and time]
Address: [address]
Special notes: [anything extra]

Write a professional booking confirmation message I can send via text or email.
Include what they should do to prepare and what to expect.
```

### Lesson 2: Reschedule Request Response
```
Client [name] wants to reschedule their [date] appointment.
They said: "[their message]"

Write a friendly reply that confirms the reschedule,
offers 2–3 alternative time slots (fill in placeholders),
and keeps the relationship warm.
```

### Lesson 3: Cancellation Policy Message
```
Client [name] cancelled with [X hours/days] notice.
My policy is: [describe your policy].

Write a message that enforces the policy professionally
without damaging the relationship, and leaves the door open for rebooking.
```

### Lesson 4: Service Complaint Response
```
Client complaint: "[paste what they said]"
What actually happened: [your side of the story]

Write a response that:
1. Acknowledges their concern without admitting fault unnecessarily
2. Offers a resolution (re-clean, partial refund, etc.)
3. Protects the business relationship
```

### Lesson 5: Review Request Message
```
I just completed a cleaning for [client name] at [address].
Job went great.

Write a short, natural text message asking them to leave a Google/Yelp review.
Include a placeholder for the review link. Keep it under 3 sentences.
```

### Lesson 6: Referral Ask Message
```
[Client name] has been a client for [X months/cleanings].
Write a short, friendly message asking them to refer a friend,
and mention the referral reward I offer: [your offer, e.g., $20 off next clean].
```

## Module 03 — Team Schedules (6 Lessons)
*Plan the week and the cover in minutes.*

### Lesson 1: Weekly Schedule Builder
```
Team members: [list names and any constraints, e.g., "Maria — no Fridays"]
Jobs this week:
- [Client name], [address], [date/time], [estimated hours], [team size needed]
- [repeat for each job]

Build an optimized weekly schedule assigning team members to jobs.
Flag any conflicts or coverage gaps.
```

### Lesson 2: Last-Minute Cover Message
```
[Team member name] just called out sick.
Their jobs today: [list jobs with times and addresses]
Available team: [list who else is working today]

Draft a message I can send to available team members asking who can cover.
Keep it urgent but not panicked.
```

### Lesson 3: Route Optimization Prompt
```
Jobs for [team member name] on [date]:
- [Client 1], [address]
- [Client 2], [address]
- [Client 3], [address]
[add more as needed]

Suggest the most efficient driving order to minimize travel time.
Starting from: [home base or first address].
```

### Lesson 4: Team Availability Tracker Message
```
Write a message I can send to my team every Sunday to collect their
availability for the upcoming week. It should be clear, easy to respond to,
and ask for any conflicts or time-off requests.
```

### Lesson 5: New Team Member Onboarding Schedule
```
I'm onboarding a new cleaner starting [date].
Experienced team members available to shadow: [names]
First week's jobs: [list]

Build a first-week schedule that pairs them with experienced staff
and gradually gives them more independence.
```

### Lesson 6: Payroll Hours Summary
```
Here are this week's hours worked by team:
[Name]: [job 1 hours], [job 2 hours], ...
[Name]: ...

Calculate total hours per person, flag anyone over 40 hours (overtime),
and format it as a clean summary I can send to payroll or use for payment.
```

## Module 04 — Checklists (5 Lessons)
*Write the checklist that keeps quality consistent.*

### Lesson 1: Standard Home Cleaning Checklist
```
Create a professional cleaning checklist for a standard home clean.
Organize by room: Kitchen, Living Room, Bedrooms, Bathrooms, Common Areas.
Format it as a checkbox list my team can use on-site or in a printed handout.
```

### Lesson 2: Deep Clean Checklist
```
Create a detailed deep cleaning checklist that goes beyond the standard clean.
Include areas often missed: baseboards, inside appliances, ceiling fans, vents, grout, etc.
Organize by room and mark which items require special products or equipment.
```

### Lesson 3: Move-In / Move-Out Checklist
```
Create a move-in/move-out cleaning checklist for a [apartment / house].
It should be thorough enough to satisfy a landlord inspection.
Include an optional section for damage notes so cleaners can document pre-existing issues.
```

### Lesson 4: Quality Control Inspection Checklist
```
Create a QC checklist a supervisor can use to inspect a completed cleaning job.
It should score or rate each area (pass/fail or 1–5),
and include a section for notes and follow-up actions.
```

### Lesson 5: Client-Specific Custom Checklist
```
Client: [name]
Special instructions they've given: [paste their requests or preferences]
Home details: [number of rooms, pets, allergies, off-limits areas, etc.]

Build a custom checklist tailored specifically to this client
that I can save in their file and hand to any cleaner assigned to their home.
```

## Module 05 — Business Workflows (5 Lessons)
*Automate the admin that eats every evening.*

### Lesson 1: End-of-Day Admin Summary
```
Here's what happened in my business today:
- Jobs completed: [list]
- Revenue collected: $[amount]
- Issues/complaints: [any?]
- No-shows or cancellations: [any?]
- Team notes: [anything notable]

Summarize this into a clean end-of-day report I can log or share with a business partner.
Highlight anything that needs follow-up tomorrow.
```

### Lesson 2: Monthly Revenue Report
```
This month's data:
- Total jobs: [number]
- Total revenue: $[amount]
- New clients: [number]
- Recurring clients: [number]
- Cancellations: [number]
- Top expense: [expense category]

Write a simple monthly business summary with insights on growth, retention,
and one recommendation for next month.
```

### Lesson 3: Client Intake Form Questions
```
Create a list of questions to ask a new client before their first cleaning.
Cover: home details, access instructions, priorities, pet info, product preferences,
how they heard about us, and billing preference.
Format it as a simple intake form I can send via email or use on a call.
```

### Lesson 4: Standard Operating Procedure (SOP)
```
Write a step-by-step SOP for: [specific process — e.g., "handling a client complaint"
/ "preparing for a deep clean job" / "locking up a client's home after cleaning"]

Format it so a new employee with no experience can follow it independently.
Include what to do if something goes wrong.
```

### Lesson 5: Weekly Business Review Prompt
```
Help me run my weekly business review. Ask me questions one at a time about:
1. Revenue vs. last week
2. Client satisfaction
3. Team performance
4. Upcoming bookings and pipeline
5. One problem I'm trying to solve

After I answer each one, summarize my week and give me 3 action items for next week.
```
